# Character model

`human-character.glb` is a **placeholder**. It is a real rigged model (one
skinned mesh per material, 18 bones, 4 animation clips), but it is low-poly and
built from simple shapes. It is generated by
[`scripts/generate-placeholder-model.mjs`](../../scripts/generate-placeholder-model.mjs)
(`npm run generate:model`).

## Missing production asset

A production version still needs an artist-made model:

| Requirement | Value |
| --- | --- |
| Format | Binary glTF 2.0 (`.glb`), textures embedded |
| Character | Friendly stylized adult man, blue + white casual outfit |
| Rig | Humanoid skeleton, skinned mesh |
| Facing | +Z (towards the camera), Y up, feet at the origin |
| Clips | `Idle` (loop), `Walk` (in-place loop, no root motion), `Wave` (one-shot, about 2 s), `Happy` (loop, for example a cheer or hop) |
| Budget | Under about 15k triangles and 2 MB, so the overlay stays light |

## Replacing it

1. Save the new file as `assets/models/human-character.glb`.
2. Clip names don't have to match exactly. `src/renderer/AnimationController.ts`
   also accepts common aliases such as `Walking`, `Armature|walk`, `Waving`,
   `Cheering`, `Jump` and `ThumbsUp`. Missing clips fall back to `Idle` and log a warning.
3. Size and position don't matter: `Mascot.tsx` rescales any model to 1.85 units
   tall and stands it on the ground.
4. Tune `WALK_STRIDE_SPEED` in `src/renderer/Mascot.tsx` until the feet stop
   sliding. It is the ground speed, in units per second, that matches one walk
   cycle at normal speed.
