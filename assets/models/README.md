# Character models

`human-character.glb` is **Aqua**, the default companion. It's a stylized
low-poly character in a blue tee with white accents, made of simple shapes. It
is generated by `src/renderer/character/procedural.ts`, the same code the
in-app character creator uses:

```bash
npm run generate:model
```

## What's in it

| Part | Details |
| --- | --- |
| Rig | 18 bones (`Root`, `Hips`, `Spine`, `Chest`, `Neck`, `Head`, `UpperArm_L/R`, `LowerArm_L/R`, `Hand_L/R`, `UpperLeg_L/R`, `LowerLeg_L/R`, `Foot_L/R`) and one skinned mesh per material |
| Face | A `Face` mesh with morph targets `happy`, `sad` and `blink` |
| Animations | `Idle`, `Walk`, `Wave` (left hand), `Drink` (IK-baked, the cap meets the mouth), `Happy`, `Sad`, `SadWalk` |
| Metadata | glTF `extras.aquamate` on the root node: body height for scaling, walk speeds that match each walk's stride, the part of the Drink clip where the bottle empties, and where the bottle sits in `Hand_R` |

The water bottle isn't part of the file. The app adds it at runtime, so it
can show the water level going down.

## A production character

The default character is fine for a prototype; a polished product would use an
artist-made model. To replace it, export a `.glb` that meets these
requirements and either save it over `human-character.glb` or upload it in
**Settings → Character**:

| Requirement | Value |
| --- | --- |
| Format | Binary glTF 2.0 (`.glb`), textures embedded, no Draco/meshopt/KTX2 compression |
| Character | Friendly, stylized, readable at about 240 px tall |
| Orientation | Y up, facing +Z, feet at the origin (any scale is fine) |
| Rig | Humanoid skeleton with a skinned mesh; a right-hand bone named like `RightHand` or `Hand_R` |
| Clips | `Idle` (loop), `Walk` (in-place loop, no root motion), `Wave` (one-shot, about 2 s), `Drink` (one-shot, about 4 s, using the right hand), `Happy` (loop), `Sad` (one-shot, about 2 s), `SadWalk` (in-place loop) |
| Face | Morph targets `happy`, `sad` and `blink`, or ARKit / VRoid equivalents |
| Budget | Under about 20k triangles and 3 MB |

### Fallbacks for missing parts

- Clip names are matched loosely: `Walking`, `Armature|walk` and
  `mixamo.com|Waving` all work.
- Missing clips fall back: Drink → Happy, Sad → Idle, SadWalk → a slower Walk.
- A model without face morph targets simply has no expressions.

### Optional metadata

To get exact bottle placement and walking speed on your own model, add this to
the root node's glTF `extras`:

```json
{
  "aquamate": {
    "version": 1,
    "height": 1.8,
    "locomotion": { "Walk": 1.4, "SadWalk": 1.0 },
    "drink": { "start": 0.2, "end": 0.7 },
    "props": { "bottle": { "bone": "RightHand", "position": [0.03, -0.06, 0.03], "quaternion": [0, 0, 0, 1] } }
  }
}
```

| Field | Meaning |
| --- | --- |
| `height` | The model's height in its own units |
| `locomotion` | Ground speed, in model units per second, that matches each walk clip |
| `drink` | The fraction of the Drink clip during which the bottle empties |
| `props.bottle` | The bottle's grip point and rotation in that bone's space |
